# Phase 3 预规划 — CTO 方向指引

> **文档类型**: CTO 战略规划  
> **前提**: Phase 2 集成验收通过  
> **目标**: 从"可玩原型"到"可发布产品"  

---

## Phase 3 核心目标

Phase 2 结束后，游戏应具备完整的核心循环。Phase 3 聚焦三个方向：

1. **内容深度** — 让每一局都有不同的体验
2. **多人联机** — 从 Host 单机到真正多人对战
3. **产品打磨** — 手感、节奏、视觉反馈

---

## 方向一：内容深度（PRD Phase 2 对应）

### 1.1 全 22 技能完整实现

**当前状态**: 22 个技能已定义（`skill_types.gd` ALL_SKILLS），但仅框架  
**Phase 3 要求**: 每个技能的被动/主动效果完整实现

| 类别 | 技能数 | 关键实现点 |
|---|---|---|
| 分析类 | 5 | 基本面扫描需计算内在价值，庄家追踪需显示持仓变动 |
| 执行类 | 5 | 批量交易需多订单并发，自动止损需 tick 级监控 |
| 防御类 | 5 | 钢铁意志需在爆仓时触发，现金为王需按 tick 计息 |
| 社交类 | 4 | 市场谣言需注入假新闻，跟风大师需读取其他玩家订单方向 |
| 激进类 | 3 | 杠杆狂人需修改资金上限，全押需限制持仓数量 |

**归属**: WS2（技能效果）+ WS3（资金/持仓修改）+ WS5（UI显示）

### 1.2 成就系统完整化

**当前状态**: 10 个成就已注册，仅 3 个有检测逻辑  
**Phase 3 要求**: 
- 补全所有 10 个成就检测
- 成就解锁时 UI 弹窗 + 音效
- 成就奖励发放（技能解锁/保险柜升级/资金奖励）
- 新增 10+ 个成就（按 PRD §Ch.31 成就系统设计）

**归属**: WS3（检测逻辑）+ WS5（弹窗UI）

### 1.3 Boss 系统完整化

**当前状态**: Boss 入场/交易/广播框架就绪，但击败判定和奖励未实现  
**Phase 3 要求**:
- Boss 击败条件: Boss 亏损或爆仓
- 击败奖励: 在 Boss 对面的玩家获得额外积分/资金
- Boss 专属动画/音效
- 每时代 Boss 有独特行为模式

**归属**: WS2（行为逻辑）+ WS4（广播）+ WS5（UI反馈）

## 方向二：多人联机

### 2.1 匹配系统

**新增文件**: `src/server/session/matchmaking.gd`（WS4 新增）  
**要求**:
- 快速匹配: 玩家点击"开始"后自动匹配同段位玩家
- Bot 填充: 匹配超时（10s）后用 Bot 填充空位
- 房间管理: 创建/加入/离开房间

### 2.2 多人同步完善

**当前状态**: ENet 基础通信就绪，但以下场景未覆盖  
**Phase 3 要求**:
- 玩家断线后 Bot 接管（非直接踢出）
- 状态预测: 客户端乐观渲染 + 服务端纠正
- 聊天系统: 预设快捷消息（"快撤离！"/"跟庄！"）

### 2.3 排行榜系统

**新增文件**: `src/server/player/leaderboard_manager.gd`（WS3 新增）  
**要求**:
- 全局排行: 按累计利润/胜率/段位排序
- 好友排行: 本地好友列表
- 赛季排行: 每月重置

**归属**: WS3（数据）+ WS4（网络）+ WS5（UI）

---

## 方向三：产品打磨

### 3.1 视觉反馈系统

**WS5 任务**:
- 盈利动画: 买入获利时绿色数字飘升
- 亏损动画: 亏损时红色数字飘落
- 撤离成功: 全屏金色特效 + 音效
- 爆仓: 屏幕震动 + 红色闪烁 + 音效
- Boss 入场: 专属过场动画

### 3.2 时代氛围差异化

**WS5 任务**:
- 每个时代有独特的配色方案（DarkTheme 扩展）
- 时代专属背景音乐
- 股票名称/代码的时代感（如上海2007用中文名，硅谷2000用英文缩写）

### 3.3 新手引导

**新增文件**: `src/client/ui/screens/tutorial_screen.gd`（WS5 新增）  
**要求**:
- 首次进入游戏时触发
- 分步引导: 选股 → 买入 → 观察新闻 → 撤离
- 可跳过，可在设置中重新触发
