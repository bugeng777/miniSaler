## 二、新功能整体验收（按游戏流程）

### 准备阶段（LOADOUT）

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| 30s 倒计时 | 进入准备阶段，观察倒计时数字 | 从 30 递减到 0 |
| 超时自动提交 | 不操作等倒计时结束 | 自动进入入局阶段 |
| 技能选择 | 选择 2 个技能，点击入局 | 技能栏显示 2 个技能按钮 |

### 入局阶段（ENTER_MARKET）

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| 股票名称显示 | 进入交易屏幕，观察左侧股票列表 | 显示中文名 + 价格 |
| 5 时代各有不同股票 | 分别选择 5 个时代进入 | 每个时代 8 只不同股票 |
| Bot 注册 | 进入交易后检查 PlayerManager | 7 个 Bot + 1 个玩家 = 8 个参与者 |

### 交易阶段（TRADING）

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| K 线实时更新 | 观察 K 线图 | 每 0.5s 新增一个数据点 |
| 排行榜更新 | 观察右侧排行榜 | 8 个玩家按资产排序 |
| 顶栏资产更新 | 买入/卖出后观察顶栏 | 现金和总资产实时变化 |
| 新闻推送 | 等待 8-15 秒 | 底部新闻栏显示新闻 |
| 时代专属新闻 | 选择香港1997，等待新闻 | 可能出现"索罗斯做空"等专属新闻 |
| 订单成交链 | 市价买入 10 股 | OrderBook → PlayerManager → 持仓更新 |
| 做空保证金验证 | 无足够保证金时做空 | 订单被拒绝 |
| 技能冷却显示 | 点击主动技能 | 按钮显示冷却倒计时 |

### 撤离/爆仓

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| 撤离窗口显示 | 等待撤离窗口开放 | 撤离按钮变绿，倒计时显示 |
| 撤离成功 | 有利润时点击撤离 | 进入结算，显示"撤离成功" |
| 爆仓触发 | 大量做空 + 价格反向 | 自动进入结算，显示"爆仓" |

### 结算阶段（SETTLEMENT）

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| 排行榜 | 进入结算屏幕 | 显示所有玩家排名 |
| 段位变化 | 观察段位积分 | 显示 "+50" 或 "-20" |
| 利润颜色 | 盈利/亏损局 | 绿色/红色 |
| 存档持久化 | 结算后退出重进 | 累计数据保留 |
| 成就解锁 | 首次撤离成功 | 成就列表新增"初次撤离" |

### 再来一局

| 验收项 | 验证方法 | 预期结果 |
|---|---|---|
| 状态重置 | 再来一局 → 时代选择 | 交易屏幕 K 线清空、股票列表清空 |
